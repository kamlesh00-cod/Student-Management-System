# Student-Management-System
A console-based Student Management System built with Java featuring CRUD operations, file persistence, validation, and custom exception handling.

Features 

    Add a new student

    View all students

    Search student by roll number

    Update student information

    Delete student

    Prevent duplicate roll numbers

    Validate student age

    Automatically format student names

    Save student data to a file

    Load student data when the application starts

    Handle invalid and corrupted file records

    Custom exception handling
